# 🔐 SecurePass Analyzer

SecurePass Analyzer is an interactive cybersecurity application designed to evaluate password strength, detect breached credentials, and simulate real-world attack scenarios.

## 🚀 Features
- Password Strength Analysis
- Breach Detection
- Crack Time Estimation
- Dictionary Attack Simulation
- Brute Force Attack Demo
- Strong Password Generator
- Visual Strength Meter

## 🛠 Built With
- Python
- Streamlit

## 🎯 Purpose
This project demonstrates practical cybersecurity concepts including password security, attack modeling, and defensive strategies.

## ▶️ Run Locally
pip install -r requirements.txt  
python -m streamlit run app.py
